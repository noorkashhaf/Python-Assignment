# Python Assignment 3

## About the Project
This repository contains my solutions to Assignment 3, completed as part of my Python programming practice.

The assignment focuses on developing fundamental Python programming skills, including functions, conditional statements, mathematical operations, object-oriented programming, and inheritance.

## Exercises Included

### 1. Lambda Function
- Used a lambda function to multiply two numbers.
- Tested the function with the values 5 and 6.

### 2. Calculating the Area of a Circle
- Used Python's `math` module.
- Created a function to calculate the area of a circle using its radius.

### 3. Basic Calculator
- Created a calculator function that performs four operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Used conditional statements (`if`, `elif`, and `else`) to select the operation.

### 4. Rectangle Class
- Created a `Rectangle` class.
- Used a constructor to initialise length and width.
- Created a method to calculate the area of a rectangle.

### 5. Classes and Inheritance
- Created a parent class called `Shape`.
- Created a child class called `Square`.
- Used inheritance and the `super()` function.
- Implemented methods to calculate the area and describe the square.
